在使用中文版 Microsoft Word 或 WPS 时，我们习惯使用“初号”、“小初”、“一号”……“五号”、“小五”等中文专有字号名称。然而在国际通用标准、非中文操作系统（如英文版、日文版 Office）、桌面出版软件（Adobe InDesign、Illustrator）以及网页 CSS 设计中，字号通常统一以**磅**（Point，缩写为 **pt**）或**毫米**（mm）作为度量单位。

例如在日文版 Word 中，默认正文字体大小标注为 `10.5`，其实对应的正是中文版里的“五号”；而高校毕业论文中常见的“正文小四号”，在英文排版中对应的正是标准的 `12 pt`。

为了在不同语言环境和排版工具之间无缝切换，本文整理了最完整的中文字号、磅数、毫米换算表及常用排版规范。

## 2. 核心原理与单位换算

为什么会有诸如 `10.5 pt`、`6.875 pt` 这样看似奇怪的半数或小数？这源于现代桌面出版系统（DTP）中的磅值定义以及历史铅字体系的演变。

### 2.1 磅（Point，pt）的换算定义

现代计算机排版采用的是 **PostScript 点制标准（DTP 点制）**，定义为**每英寸等于 72 磅**：

$$ 1 \text{ inch} = 72 \text{ pt} = 25.4 \text{ mm} $$

根据该基准，可以得出磅数与毫米的精确折算公式：

$$ 1 \text{ pt} = \frac{25.4}{72} \text{ mm} \approx 0.352778 \text{ mm} $$

反向换算：

$$ 1 \text{ mm} \approx 2.8346 \text{ pt} $$

### 2.2 为什么中文字号会出现 10.5 磅？

中文字号的历史可追溯到 19 世纪美华书局（American Presbyterian Mission Press）在上海引入活字印刷时创立的“美华字号系统”。当时根据汉字方块特点将铅字分成初号至七号等若干规格。

进入计算机文字处理时代后，微软为适配中文排版习惯，将这套流传百年的铅字高度折算为对应的 PostScript 磅数。例如传统“五号”铅字高度约 $3.7 \text{ mm}$，折算后最接近的整半磅数就是：

$$ 10.5 \text{ pt} \times 0.352778 \text{ mm/pt} \approx 3.704 \text{ mm} $$

这就解释了为何英文版 Word 默认正文是 11 pt 或 12 pt，而中文版/日文版默认则是 10.5 pt。

## 3. 两大官方与学术排版规范速查

在撰写正式文档时，按规范设置字号是排版考核的核心要求：

### 3.1 本科 / 硕博学术论文通用字号规范

| 内容模块 | 推荐字号 | 推荐字体 | 推荐行距 |
| :--- | :--- | :--- | :--- |
| **论文主标题** | 二号（21 pt）或 小二号（18 pt） | 黑体 / 华文中宋 | 单倍行距或固定值 24 pt |
| **一级标题（章）** | 三号（16 pt）或 小三号（15 pt） | 黑体，居中加粗 | 段前 1 行，段后 0.5 行 |
| **二级标题（节）** | 四号（14 pt） | 黑体，顶格 | 段前 0.5 行，段后 0.5 行 |
| **三级标题（小节）** | 小四号（12 pt） | 黑体，顶格 | 段前 0.25 行，段后 0.25 行 |
| **正文内容** | **小四号（12 pt）** | 中文宋体，西文 Times New Roman | 1.25 ~ 1.5 倍行距（或固定值 20~22 pt） |
| **图题 / 表题** | 五号（10.5 pt） | 中文宋体/黑体，西文 Times New Roman | 单倍行距 |
| **表内内容 / 附注** | 小五号（9 pt）或 五号（10.5 pt） | 宋体 | 单倍行距 |
| **页眉 / 页脚** | 小五号（9 pt） | 宋体 / Calibri | 单倍行距 |
| **参考文献列表** | 五号（10.5 pt）或 小五号（9 pt） | 宋体 / Times New Roman | 单倍行距 |

### 3.2 《党政机关公文格式》（GB/T 9704-2012）国家标准

国家标准对公文排版有极严密的字号与字体规范，切勿混用：

- **公文发文字号**：四号（14 pt）仿宋体。
- **公文首页标题**：二号（21 pt）小标宋体，居中排布。
- **正文一级标题**：三号（16 pt）黑体。
- **正文二级标题**：三号（16 pt）楷体_GB2312（加粗）。
- **公文正文内容**：**三号（16 pt）仿宋_GB2312**，一般每面排 22 行，每行排 28 个字。
- **公文附件说明与附注**：三号（16 pt）仿宋体。

## 4. 跨平台与开发排版实用技巧

### 4.1 在非中文版 Word / Pages 中直接输入数字

如果当前使用的是英文版、日文版 Office 或 macOS Pages，字号下拉菜单中没有“小四”、“三号”选项：

> **实用技巧**：选中字号输入框，**直接键入阿拉伯数字磅数并按回车**即可。例如直接输入 `12` 代表小四号，输入 `10.5` 代表五号，输入 `16` 代表三号。

### 4.2 Web 前端（CSS）中的 px 与 pt 换算

在网页排版或打印样式表（`@media print`）中，显示器屏幕通常以标准 96 DPI 计算：

$$ 1 \text{ pt} = \frac{96}{72} \text{ px} \approx 1.3333 \text{ px} $$

- **小四号（12 pt）**：$12 \times 1.3333 = 16 \text{ px}$（正好是现代浏览器默认的基准字号 `1rem = 16px`）
- **五号（10.5 pt）**：$10.5 \times 1.3333 = 14 \text{ px}$（常用于网页辅助性文本或小正文）
- **小五号（9 pt）**：$9 \times 1.3333 = 12 \text{ px}$（常用于网页微型标签、版权声明）

```css
/* 打印媒体样式参考示例 */
@media print {
  body {
    /* 对应学术论文正文小四号 */
    font-size: 12pt;
    line-height: 1.5;
  }
  h1 {
    /* 对应三号标题 */
    font-size: 16pt;
  }
  footer {
    /* 对应小五号页脚 */
    font-size: 9pt;
  }
}
```

### 4.3 LaTeX 中的中文字号设置

使用 LaTeX 编写毕业论文（通常基于 `ctex` 宏包）时，可以直接使用内置的 `\zihao{}` 宏命令，参数与中文字号直接对应：

```latex
\zihao{2}   % 二号 (21 pt)
\zihao{-2}  % 小二号 (18 pt)
\zihao{3}   % 三号 (16 pt)
\zihao{-3}  % 小三号 (15 pt)
\zihao{4}   % 四号 (14 pt)
\zihao{-4}  % 小四号 (12 pt，正文默认)
\zihao{5}   % 五号 (10.5 pt)
\zihao{-5}  % 小五号 (9 pt)
```
其中负号 `-` 就代表“小”字号，非常简洁直观。
